# Factorio Mod Portal — paste-ready summary

## English (short)

Loaders and high-speed inserters for **Ultimate Belts Space Age**, with optional **Double Speed Belts** compatibility.

- 1×1 loaders for every UBSA belt tier (and vanilla/SA belts when DSB is enabled)
- High-speed inserters from **ultra-fast** upward, scaled to belt throughput
- Loader GUI: **Split lanes** and **Overfill machines**
- Speeds resync after Double Speed Belts rewriting belt speeds

**Requires** Ultimate Belts Space Age and/or Double Speed Belts (Factorio 2.0 / Space Age).

## Русский (кратко)

Погрузчики и сверхбыстрые манипуляторы для **Ultimate Belts Space Age**, с совместимостью **Double Speed Belts**.

- Погрузчики 1×1 для всех уровней UBSA (и для обычных/турбо лент при DSB)
- Манипуляторы начиная со **сверхбыстрого** уровня, под скорость ленты
- В меню погрузчика: **Разделять полосы** и **Переполнять механизмы**
- Скорости подстраиваются после пересчёта Double Speed Belts

**Нужен** Ultimate Belts Space Age и/или Double Speed Belts (Factorio 2.0 / Space Age).
